Approach — multi-source BFS (stop at the first opposite cell)

Since the grid has no walls, BFS step-count equals Manhattan distance. Seed the queue with every cake at distance 0 and flood 4-directionally; the first person dequeued gives the global minimum — no per-cell distances needed.

read grid (m x n)
cakes  = [(r,c) for cell == '1']
persons_exist = any cell == '0'
if not cakes or not persons_exist: return -1

dist = [[-1]*n for _ in range(m)]
q = deque()
for (r,c) in cakes: dist[r][c] = 0; q.append((r,c))
while q:
    r, c = q.popleft()
    for nr, nc in 4-neighbours(r, c):
        if in-bounds and dist[nr][nc] == -1:
            if grid[nr][nc] == '0':      # first person reached
                return dist[r][c] + 1
            dist[nr][nc] = dist[r][c] + 1
            q.append((nr, nc))
return -1

O(m·n) time and space (each cell enqueued once). A brute-force person×cake pair check would be O((m·n)²) — far too slow for m,n ≤ 2000.

Variants & contrast

  • This — single global minimum over all person↔cake pairs (stop at the first opposite cell).
  • #10049 / #542 — fill every cell with its nearest-source distance (don't early-stop).
  • #10016 — the bundled cake/person round this cleanly standalone-izes.

Follow-up trio

  • Multi-threaded — level-synchronous BFS: expand each distance layer's frontier in parallel, dedup into the next; the early-stop becomes "stop the round the first person appears."
  • Streaming — cells/cakes arrive online: maintain the BFS layers and re-expand only from newly added sources; report the running minimum.
  • O(1)-space — the dist grid is O(m·n) (needed to mark visited). Reusing the input grid in place (overwrite with a visited marker) avoids a second array.
