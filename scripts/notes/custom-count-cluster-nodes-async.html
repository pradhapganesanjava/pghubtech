Approach — traverse the cluster, dedup by node id

A cluster is a graph (cycles possible), so the count is "number of reachable nodes from root" via BFS/DFS — with a visited set so each node is counted once. Each step sendAsyncMessage(node) asks for its neighbors; receiveMessage() delivers them.

def count(root):
    seen = {id(root)}
    frontier = [root]
    while frontier:
        for node in frontier:
            sendAsyncMessage(node)          # ask each for neighbors
        nxt = []
        for _ in range(len(frontier)):
            for nb in receiveMessage():     # neighbors reported back
                if id(nb) not in seen:
                    seen.add(id(nb)); nxt.append(nb)
        frontier = nxt
    return len(seen)

Follow-up 1 — return the structure, not the count

Instead of a counter, record adj[node] = [neighbors] as replies arrive — that adjacency map IS the cluster topology. Recreating nodes + relinking via an old→new map is exactly Clone Graph (#133).

Follow-up 2 — messages fail / are retried → stay correct

  • Idempotency — key the seen set by a stable node id, so a re-delivered or duplicate reply is a no-op; counting is set-insertion, never +1 per message. Retried messages cannot double-count.
  • At-least-once + dedup — pair each sendAsyncMessage with a timeout; resend on no reply. Because receive is idempotent, at-least-once delivery is safe.
  • Completion — track outstanding (sent-but-unacked) messages; the traversal is done when the frontier is empty AND no message is in flight.

Follow-up trio

  • Multi-threaded — a worker pool drains a queue of nodes, sends async probes, and folds replies into a concurrent visited set (lock / sharded set) — exactly LC 1242 Web Crawler Multithreaded. Stop when the queue is empty and all workers idle.
  • Streaming — nodes/edges discovered incrementally: keep the visited set live and emit the running count as new nodes are deduped in.
  • O(1)-space — the visited set is inherently O(V) (needed for correctness over cycles + retries). If the cluster is a guaranteed acyclic tree with no retries, a pure recursive count is O(height) extra.
