Approaches

1) Single removal — O(n)

One DFS from the root that skips the removed subtree; take the max depth of everything else.

def height_without(removed):
    best = 0
    def dfs(u, parent, d):
        nonlocal best
        if u == removed: return        # prune the whole subtree
        best = max(best, d)
        for w in adj[u]:
            if w != parent: dfs(w, u, d + 1)
    dfs(root, 0, 0)
    return best

2) All removals (every v) — O(n)

Compute depth[] with a DFS and lay nodes out in Euler (entry) order. Each subtree is then a contiguous range [tin[v], tout[v]], so the height after removing subtree(v) is just the max depth outside that range — a prefix/suffix max.

dfs sets depth[u], tin[u], tout[u], and order[]   # Euler entry order
pre[i] = max(depth[order[0..i]])     # prefix max of depth
suf[i] = max(depth[order[i..]])      # suffix max of depth
def ans(v):
    l, r = tin[v], tout[v]
    return max(pre[l-1] if l > 0 else -1,
               suf[r+1] if r+1 < n else -1)

The general "answer for every node as root" version instead uses the classic re-rooting two-pass: a post-order down-pass for each node's subtree height, then a pre-order up-pass that hands each child the parent's best height excluding that child (keep the top-2 child depths so the exclusion is O(1)).

Follow-up trio

  • Multi-threaded — the down-pass over disjoint subtrees is independent: fork-join per child, max-combine. The Euler prefix/suffix maxes are parallel scans.
  • Streaming — removal/restore queries arrive online: maintain a multiset (or segment tree) of depths keyed by Euler position; removing subtree(v) = exclude one contiguous range → range-max query in O(log n) per query.
  • O(1)-space — for a single removal, iterative DFS with a parent pointer skips the subtree in O(1) extra (no recursion). The all-v arrays are inherently O(n) (one answer per node).

Contrast — the tree-deletion family (different semantics)

  • This (#10052) — remove a node deletes its entire subtree; height of the rest.
  • #10006 — a deleted node is skipped (children pass through); minimize deletions to bound height ≤ K.
  • #10051 — delete but keep root + connectivity; maximize depth (reduces to height).
