Approach

  1. Store — Map<filename, Set<token>> for O(1) membership, plus an inverted index Map<token, Set<filename>> so GetAllFiles never rescans every document.
  2. Evaluate the predicate with the classic operator-precedence parser — two stacks (operands + operators) or recursive descent. Parentheses highest, then && binds tighter than ||. Operands resolve to booleans (token membership) instead of numbers.
  3. CheckContains(filename, predicate) — evaluate the expression against that one document's token set.
  4. GetAllFiles(predicate) — evaluate the parse tree over the inverted index with set operations: && = intersection, || = union.

In one line: Basic Calculator III precedence/parens evaluation with boolean operands, layered on an inverted-index boolean-retrieval store. Complexity: build O(total tokens); CheckContains O(predicate); GetAllFiles O(predicate × matched files).
