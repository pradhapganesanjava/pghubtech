Approach — Multi-Source BFS

Flood out from every Bathroom at once. Seed a queue with all 'B' cells at distance 0, then BFS 4-directionally; the first time a cell is reached is its shortest distance to some bathroom. Finally read the distances off the Desk cells.

read grid (m x n)
dist = [[-1]*n for _ in range(m)]      # default -1 (also the unreachable answer)
q = deque()
for each cell (i,j):
    if grid[i][j] == 'B':
        dist[i][j] = 0; q.append((i,j))
while q:
    i, j = q.popleft()
    for (ni, nj) in 4-neighbours(i, j):
        if in-bounds and dist[ni][nj] == -1 and grid[ni][nj] != 'B':
            dist[ni][nj] = dist[i][j] + 1
            q.append((ni, nj))
# emit: dist[i][j] if grid[i][j]=='D' else -1   (unreached D stays -1)

One BFS over the whole grid (not one BFS per desk) — O(m·n) time and space. Walls don't exist here (every non-B/D cell is walkable), so BFS step-distance equals the Manhattan distance.

What's different from the textbook versions

  • Output only at 'D' cells. Standard 01-Matrix / Walls-and-Gates fill EVERY cell; here non-Desk cells are forced to -1 — a post-filter, the BFS itself is unchanged.
  • -1 serves double duty — it's both the "not a Desk" sentinel and the "Desk can't reach any Bathroom" answer (a Desk simply never dequeued).
  • Zero Bathrooms is legal — the queue starts empty, BFS does nothing, every Desk stays -1.
  • "Nearest", not "all". This is min-distance to the closest bathroom (one multi-source BFS). Summing distance to EVERY bathroom (#317) instead needs a separate BFS per source.
  • "Manhattan" is a red herring — with no obstacles, 4-dir BFS step count already equals Manhattan distance; you do not compute |dx|+|dy| directly (that would ignore reachability / the "can't reach" case).
