Approach

Keep a base dict plus a stack of override layers — one dict per open transaction.

  • set(k, v) — write to the top layer (or the base if no transaction is open).
  • get(k) — search the layers top-down, then the base; return the first hit. Represent deletes with a tombstone so a transaction can shadow a base key.
  • begin() — push a new empty layer. O(1).
  • rollback() — pop the top layer. O(1).
  • commit() — merge the top layer down into the next layer (or the base). O(changes in the layer); begin/rollback stay O(1). Nesting falls out for free.
class KV:
    TOMB = object()
    def __init__(self):
        self.base = {}
        self.stack = []                 # stack of override dicts
    def get(self, k):
        for layer in reversed(self.stack):
            if k in layer:
                v = layer[k]
                return None if v is self.TOMB else v
        return self.base.get(k)
    def set(self, k, v):
        (self.stack[-1] if self.stack else self.base)[k] = v
    def begin(self):    self.stack.append({})          # O(1)
    def rollback(self):
        if self.stack: self.stack.pop()                # O(1)
    def commit(self):
        if not self.stack: return
        top = self.stack.pop()
        dst = self.stack[-1] if self.stack else self.base
        dst.update(top)                                # O(changes)

Multi-threaded extension

  • Transactions are per-thread — keep the override stack in thread-local state so threads don't see each other's uncommitted writes.
  • Reads vs writes — a ReadWriteLock on the base map (many readers, one writer), or copy-on-write snapshots so readers never block.
  • Commit — take the write lock and apply the layer atomically. For higher concurrency use optimistic concurrency: record the base versions a transaction read, and on commit re-check them under the lock; abort + retry on conflict.
