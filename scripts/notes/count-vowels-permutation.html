#1220 · Count Vowels Permutation

Hard · Top-down memo → 5 rolling variables · count walks, do not build strings

Idea. A valid string is a walk of length n on a 5-node graph. vowel_permutation_count(i, vowel) = how many length-i strings end with that vowel. Cache every (i, vowel) so each state is solved once.

Rules = directed edges

“Followed by” is one-way. a → e means ae, not ea.

a→e
e→a i
i→a e o u (not i)
o→i u
u→a
Why invert? The function asks “who can sit in front of this new last letter?” New last a comes from e i u (those are the letters that may be followed by a). ae is counted in the e bucket — it ends with e.

Recurrence · length i, ending with …

a
count(i,a) = count(i−1,e) + count(i−1,i) + count(i−1,u)
e
count(i,e) = count(i−1,a) + count(i−1,i)
i
count(i,i) = count(i−1,e) + count(i−1,o)
o
count(i,o) = count(i−1,i)
u
count(i,u) = count(i−1,i) + count(i−1,o)
1
Base — i == 1: return 1 (the single letter itself).
2
Answer — sum count(n, v) for v in aeiou, then % (10⁹+7).
3
Memo — @cache on (i, vowel). 5n states, O(1) work each → O(n).

Code

import functools

class Solution:
    def countVowelPermutation(self, n: int) -> int:
        MOD = 10 ** 9 + 7
        @functools.cache
        def vowel_permutation_count(i, vowel):
            total = 1                          # i == 1
            if i > 1:
                if vowel == 'a':
                    total = (vowel_permutation_count(i - 1, 'e')
                           + vowel_permutation_count(i - 1, 'i')
                           + vowel_permutation_count(i - 1, 'u')) % MOD
                elif vowel == 'e':
                    total = (vowel_permutation_count(i - 1, 'a')
                           + vowel_permutation_count(i - 1, 'i')) % MOD
                elif vowel == 'i':
                    total = (vowel_permutation_count(i - 1, 'e')
                           + vowel_permutation_count(i - 1, 'o')) % MOD
                elif vowel == 'o':
                    total = vowel_permutation_count(i - 1, 'i')
                else:
                    total = (vowel_permutation_count(i - 1, 'i')
                           + vowel_permutation_count(i - 1, 'o')) % MOD
            return total

        return sum(vowel_permutation_count(n, vowel) for vowel in 'aeiou') % MOD
Time O(n) · 5n cached calls Space O(n) · memo + recursion stack
OPTIMAL · O(1) SPACE

From recursion to 5 variables

The trick. Memo is a table of size n × 5. Look at any recurrence: count(i, ·) only reads count(i−1, ·). You never need length i−2. So drop the table. Keep five numbers — the current length’s counts — and overwrite them each step.

1 · See the memo as a table

Each recursive call writes one cell. After memo fills, it looks like this (row = length):

length iaeiousum
i = 1 base111115
i = 23221210
i = 36532319

Recursion fills this from the bottom (asks for n, then n−1, …, hits 1, then returns up). A loop fills the same cells from the top — row 1, then 2, then 3. Same numbers.

2 · Drop every row you don’t need

1
2D memo dp[i][vowel] — O(n) space. Recursion stack also O(n).
2
Two rows — only prev[5] and cur[5]. After each length, prev = cur.
3
Five scalars — name them after the vowels. The names are the previous row. Compute a new 5-tuple in one assignment.
# the recursive cell becomes the variable of the SAME vowel count(i, 'a') → a # strings of current length ending in a count(i, 'e') → e count(i, 'i') → i count(i, 'o') → o count(i, 'u') → u # a recurrence copies over with a find-replace: count(i, a) = count(i-1,e) + count(i-1,i) + count(i-1,u) ↓ new_a = e + i + u
The one trap. On the right-hand side, e i u are the old length’s counts. If you write a = e + i + u and then e = a + i, the second line uses the new a — mixed lengths, wrong answer. Build all five next values from the old five, then assign together.

3 · One step is just renaming

Start at length 1 — same base as return 1 in the recursive function:

Repeat n − 1 times. The recursive version did the same n − 1 hops down to the base; the loop hops up from the base. Stop when the variables hold length n, then sum them.

4 · Optimal code

class Solution:
    def countVowelPermutation(self, n: int) -> int:
        MOD = 10 ** 9 + 7
        a = e = i = o = u = 1          # length 1
        for _ in range(n - 1):
            a, e, i, o, u = (
                (e + i + u) % MOD,     # new a  ←  old e,i,u
                (a + i) % MOD,         # new e  ←  old a,i
                (e + o) % MOD,         # new i  ←  old e,o
                i % MOD,               # new o  ←  old i
                (i + o) % MOD,         # new u  ←  old i,o
            )
        return (a + e + i + o + u) % MOD
Time O(n) · n−1 steps, 5 adds each Space O(1) · five ints, no stack
How to derive it in an interview. Write the recursive function first. Then say: “every call depends only on length i−1, so I can iterate length 1→n and keep five running counts.” Copy the five if vowel == … branches into the tuple. Tuple-unpack so old values stay intact. Done.
ELEGANT · FORWARD DFS (SUCCESSORS)

Walk next letters, not previous

Meaning. count(i, vowel) = ways to finish a length-n string after placing vowel at position i. Follow the rule map as written: from here, only recurse to allowed next letters. Start at position 1. When i == n the nth letter is already chosen → 1 complete string.

1 · Top-down + cache + MOD

from functools import cache

class Solution:
    def countVowelPermutation(self, n: int) -> int:
        MOD = 10**9 + 7
        NEXT = {
            'a': ['e'],
            'e': ['a', 'i'],
            'i': ['a', 'e', 'o', 'u'],
            'o': ['i', 'u'],
            'u': ['a'],
        }

        @cache
        def count(i, vowel):
            if i == n:
                return 1
            return sum(count(i + 1, nxt) for nxt in NEXT[vowel]) % MOD

        return sum(count(1, c) for c in 'aeiou') % MOD
@cache on (i, vowel) · 5n states % MOD on child-sum and on the 5 starts
Index pairing. Start count(1, c) + stop i == n fills positions 1 … n (length n). Start count(0, c) with the same stop would fill 0 … n → length n+1. Don’t mix them.

2 · Same recurrence, 5 variables

Each call only reads count(i+1, ·), so fill from the end. At position n every vowel is already a finished string → all ones. Walk back n−1 steps to position 1. Each variable becomes the sum of its successors.

# NEXT[vowel] copied into the tuple new_a = e # a → e new_e = a + i # e → a, i new_i = a + e + o + u # i → a, e, o, u new_o = i + u # o → i, u new_u = a # u → a 
class Solution:
    def countVowelPermutation(self, n: int) -> int:
        MOD = 10**9 + 7
        a = e = i = o = u = 1          # position n
        for _ in range(n - 1):         # walk back to position 1
            a, e, i, o, u = (
                e % MOD,               # a → e
                (a + i) % MOD,         # e → a, i
                (a + e + o + u) % MOD, # i → a, e, o, u
                (i + u) % MOD,         # o → i, u
                a % MOD,               # u → a
            )
        return (a + e + i + o + u) % MOD
Time O(n) Space O(1) · five ints

n = 1: loop skipped, (1+1+1+1+1) % MOD = 5. Base ones need no MOD — they are the five count(n, ·) ones. Tuple unpack keeps the right-hand side on the old five values.

Dual of the section above. Predecessor DP grows length 1 → n (new_a = e+i+u). This one walks position n → 1 along NEXT (new_a = e). Same answer; this map matches the problem statement one-for-one.
