Approach — topological-order bitmask propagation

The alphabet is fixed at 26, so each letter set is one 26-bit integer; unions are bitwise OR. Push each node's accumulated masks to its successors in topological order.

indeg, adj from edges
allow[v]    = bitmask of Allow(v)        # seed with own letters
disallow[v] = bitmask of Disallow(v)
A = allow[:]   ; D = disallow[:]          # accumulators

q = deque(v for v in V if indeg[v] == 0)  # Kahn (graph is a DAG)
while q:
    u = q.popleft()
    for w in adj[u]:
        A[w] |= A[u]                       # ancestors' allows flow down
        D[w] |= D[u]                       # ancestors' disallows flow down
        indeg[w] -= 1
        if indeg[w] == 0: q.append(w)

for v in V:
    eff = A[v] & ~D[v]                     # allow minus disallow
    print(letters(eff) sorted  or  '-')

O(V + E) time (one bitwise OR per edge), O(V) for the masks. Because we process in topo order, by the time a node is dequeued its A/D already include all ancestors. Disallow wins ties (the final & ~D).

Follow-up trio

  • Multi-threaded — process Kahn wave by wave (a level is a barrier); within a wave, fan the nodes out across threads. Successor masks are written by multiple sources, so OR into them under a lock / use atomic OR, or accumulate per-source then merge. (Java ExecutorService + AtomicLong masks; Python: process pool, GIL-bound otherwise.)
  • Streaming — edges or label changes arrive online. On a new edge u→v or an updated allow/disallow, OR the delta forward to all descendants (BFS from the changed node) and recompute their Effective — no full re-propagation.
  • O(1)-space — the masks are already O(1) per node (one int each); working space beyond the A/D arrays + topo queue is O(1). Output is inherently O(n) sets. Iterative Kahn avoids recursion entirely.
