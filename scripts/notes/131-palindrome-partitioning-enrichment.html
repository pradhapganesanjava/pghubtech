📐 Pattern notes — Palindrome Partitioning (131)

Backtracking (partition-on-string)

At each index, try every prefix that is a palindrome, recurse on the rest, then undo. Output size is exponential, so this is the intended approach (n ≤ 16).

res = []
def backtrack(start, path):
    if start == len(s):
        res.append(path[:]); return
    for end in range(start + 1, len(s) + 1):
        if isPal[start][end - 1]:
            path.append(s[start:end])
            backtrack(end, path)
            path.pop()
backtrack(0, [])
return res

isPal DP precompute (O(1) palindrome checks)

Precompute isPal[i][j] once so each prefix check in the backtracking is O(1) instead of O(len).

n = len(s)
isPal = [[False] * n for _ in range(n)]
for i in range(n - 1, -1, -1):
    isPal[i][i] = True
    for j in range(i + 1, n):
        isPal[i][j] = s[i] == s[j] and (j - i < 2 or isPal[i + 1][j - 1])

Build O(n²); backtracking explores O(2ⁿ) partitions, each appended in O(n).

Follow-up trio

  • Multi-threaded — the search is a tree branching on the first palindrome prefix; fan those top-level branches across threads (each explores an independent set of partitions), then concatenate the per-branch result lists. Shared isPal is read-only.
  • Streaming — characters arrive online: keep the DFS frontier of in-progress partitions and, on each new char, extend any partition whose pending suffix just became a palindrome — emit when a partition consumes the whole prefix.
  • O(1)-space — enumeration is output-bound (exponentially many partitions), so O(1) extra isn't meaningful here. The optimal-space cousin is #132 Palindrome Partitioning II (min cuts) solved with O(n) DP, or a count-only pass that never materializes the lists.
